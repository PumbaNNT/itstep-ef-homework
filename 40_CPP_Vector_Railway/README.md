# STL Containers. vector — «Автоматизована інформаційна система залізничного вокзалу»

Файл з цим завданням був прикріплений до картки «React - Context API» (21.03.2026).

Компіляція:
- Visual Studio: створити порожній консольний проєкт і додати `main.cpp`;
- або `g++ -std=c++17 main.cpp -o railway`.

Функціонал (меню): додати потяг, усі потяги, потяг за номером, зміна часу відправлення,
сортування за часом (`operator<` + `std::sort`), потяги за станцією, запис / читання файлу `trains.txt`
(перевантажені `operator<<` / `operator>>` для `Train` і `Time`). Потяги зберігаються у `vector<Train>`.
